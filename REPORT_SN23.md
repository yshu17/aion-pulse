# SN-2 и SN-3 — передача Claude

11.10.2026. Пользователь поручил Кодексу оба шага. Оба выполнены.

## Что работает

- `watcher/toasts.py`: окна без рамки, до 3 карточек, оставшиеся ждут в очереди центра.
  Въезд справа за 220 мс, 8 секунд показа, при наведении таймер остановлен.
  Настройка `reduce_motion` выключает въезд. Текст переносится и ограничен по высоте.
- `watcher/toast_native.py`: указатели WinAPI с явными типами; `NOACTIVATE`, `TOOLWINDOW`,
  `WM_MOUSEACTIVATE → MA_NOACTIVATE`, перемещение через `SetWindowPos(SWP_NOACTIVATE)`.
  Рабочая область монитора видимого `aion.bin`, иначе основной монитор; панель задач учтена.
  Данные процесса читаются только для определения имени, без внедрения/изменений игры.
- Фон — оригинальный `v4_tooltip`, девять растягиваемых частей. Пять игровых значков:
  осада, сброс, событие, чат, предупреждение. `data/ui/toasts/` и `sources.json` включаются в EXE.
- `App.notifications` — центр; `App.toasts` — потребитель очереди. В настройках добавлена
  **«Тест уведомления»**. Щелчок по карточке открывает вкладку источника; «Принять»
  подтверждает серию; «Через 5 мин» откладывает. Закрытие программы отменяет таймеры и окна.
- При интеграции исправлены пограничные случаи SN-1: повторно откладываемые карточки,
  сохранение отсутствия звука при повторе, подтверждение серии после вытеснения первого
  события из истории, снятие уже поставленных в очередь карточек при DND/выключении источника.

- `tests/test_notify_center.py`, `tests/test_toasts.py`, `tests/test_app.py`: **52 passed**.
- Полный прогон после правок: **282 passed, 6 failed**. Причины в ранее существовавшем коде:
  1. `test_alarm::test_without_popup_only_rings`: анимация вызывается с `window=None`.
  2. `test_mapview::test_show_centres_on_place_and_zoom_keeps_point_under_cursor`: тест
     ждёт центрирование немедленно, а текущая реализация перемещает карту анимацией.
  3. `test_mapview::test_click_rings_the_point_search_and_jumps_blink_first`: нет тега blink
     в ожидаемый тестом момент (поиск/анимация).
  4. `test_mapview::test_quest_givers_toggle_and_card_lists_quests`: `current_layer` ещё не задан.
  5. `test_mapview::test_relief_theme_uses_the_radar_map_in_the_same_frame`: не для всех зон есть relief.
  6. `test_theme::test_colours_live_only_in_the_theme`: две старые константы цвета в `app.py`.
  Новая строка цвета в тостах приведена к `theme.TEXT`; прежние строки не менялись.
- Снимки реальных тостов: `docs/toast-preview.png`, `docs/toast-preview-200.png`.
  Раскладка проверена при 100/125/150/200%; проверены очередь, пауза, закрытие, повторный
  snooze, DND, отрицательные координаты монитора, неизменность foreground HWND при появлении.
- Несколько физических мониторов и эксклюзивный полноэкранный режим требуют отдельной
  проверки пользователем. Тесты координат/DPI не заменяют эти проверки.
- Источники чата/предупреждений пока используют прежние оповещения: их перевод — **SN-4**.
  Общие настройки — SN-5, расписание/напоминания — дальнейшие шаги.
