# Aion Chat Watcher

Следит за чатом Aion в реальном времени и подаёт звуковой сигнал, когда в канале
«Поиск группы» появляется сообщение с одним из ключевых слов или ссылка на отмеченный предмет.

Программа только читает файл `Chat.log`. Клиент, память игры и ввод не трогаются.

## Как работает

Клиент пишет чат в `<папка игры>\classic\Chat.log` (в `system.cfg` должно быть `g_chatlog = "1"`).
Программа читает только новые строки, берёт строки `[3.Поиск группы]`, отбрасывает ник и служебную
разметку и ищет ключевые слова в тексте (без учёта регистра, «ё» = «е»).
Ссылки на предметы (`[item:ID]`) показываются названием из каталога kb.aionempire.com, поэтому
ключевое слово находит и названия предметов в ссылках.

Справа список «Что искать» — вся броня, оружие, щиты и крылья с 45-го уровня (около 11 тыс.
предметов, kb.aionempire.com), с иконками и цветом названия по качеству, как в игре. Секции: Лата,
Кольчуга, Кожа, Ткань, Оружие, Щиты, Крылья; внутри — от высокого уровня к низкому, сначала лучшее
качество. Клик по заголовку секции сворачивает её, галочка «все» отмечает всю секцию.

В списке нет белых и зелёных (common / rare) предметов. Снаряжение Рудры и Фланаса вынесено в
закреплённую секцию «★ Рудра и Фланас» в самом верху.

Фильтры под полем «Найти»: качество (кнопки «Финал. / Миф. / Эпич. / Уник. / Легенд.» —
клик скрывает или показывает), уровень от–до, тип («Лата», «Оружие», «Оружие: Меч»,
«Украшения: Кольца»…), ✕ — сбросить. Поиск, «Все» и «все» у секции действуют только на видимые
предметы. Фильтры сохраняются в config.json.

Поле «Найти» над списком: начни печатать — список сам прокрутится к первому подходящему предмету
и подсветит его (свёрнутая секция раскроется). Ищутся все слова сразу, без учёта регистра, число
совпадает с уровнем: «меч рудр», «кираса 55». Enter или ▼ — следующий, Shift+Enter или ▲ —
предыдущий, Esc — очистить. Справа счётчик «2 / 7». Отмеченный
предмет срабатывает, если на него кинули ссылку в чат. Сообщение подходит, если совпал отмеченный
предмет **или** ключевое слово; если ничего не отмечено — ищется только по ключевым словам.

Один и тот же текст от того же игрока не звенит чаще раза в `cooldown_sec` секунд.

## Запуск

- `AionChatWatcher.exe` — или из исходников: `python main.py`.
- «Папка игры» — папка `Aion Empire` (поле само показывает полный путь к `classic\Chat.log`;
  можно вставить и прямой путь к любому `Chat.log`). Справа статус: «● Слежу», «○ Не слежу»,
  «⚠ Chat.log не найден». «Обзор…» открывает выбор папки.
- «Ключевые слова» — через запятую, применяются по Enter. Справа — режим поиска:
  - «Слово ИЛИ предмет» (по умолчанию) — совпало слово **или** ссылка на отмеченный предмет;
  - «Только слова» — галочки предметов не учитываются;
  - «Только предметы» — ключевые слова не учитываются;
  - «Слово И предмет» — нужно и слово, и ссылка на отмеченный предмет в одном сообщении.
  Если для режима чего-то не хватает, статус подскажет («нет ключевых слов», «не отмечены предметы»).
- Start / Stop. Сигналы только для новых сообщений после Start.
- Проверка игры: без запущенного клиента (`aion.bin`) Start не включает слежение, а если игру
  закрыть во время слежения (проверка раз в 5 с), оно останавливается. В обоих случаях — сигнал,
  строка в ленте и «⚠ Игра не запущена» в строке состояния. Отключается `game_check: false`.
- «Оповещение»:
  - режим **Стандартный** — один звук на пачку совпадений;
  - режим **Назойливый** (как будильник) — звук по кругу, мигает кнопка на панели задач, а в ленте
    мигает полоса с найденным сообщением и галочкой «принять». Сигнал звучит, пока есть непринятые строки;
  - **серии повторов**: игрок часто повторяет объявление («1/12 … 11/12»). Сообщения одного ника
    с тем же совпадением (тот же отмеченный предмет или то же слово) — одна серия. Пока ни одно
    сообщение серии не принято, каждое звенит как обычно; после «принять» на любом из них остальные
    приходят тихо — зелёной строкой «✓ уже принято», и ожидающие строки серии принимаются вместе.
    Серия заканчивается после 12 сообщений, через 15 минут тишины от игрока, по «Сбросить» или Stop.
    Только для назойливого режима;
  - «Реакция» (15 / 30 / 60 с / 2 мин, по умолчанию 30 с) — строка, которую не приняли за это
    время, считается пропущенной;
  - «Окно поверх игры» — дополнительно показывать окно «Найдено в чате» поверх всех окон (наведение,
    клик или ОК принимают все строки). В эксклюзивном полноэкранном режиме игры оно не видно;
  - «Громкость» — ползунок громкости звуков оповещения (0–100 %, только звуки этой программы);
  - над лентой всегда видны счётчики «Найдено / Отреагировал / Пропущено» (счёт за текущий
    запуск, «Сбросить» обнуляет);
  - «Звук» — системный сигнал, звуки Windows (Alarm, Ring…) или «Свой файл…» (WAV); ▶ — прослушать.
- «История» рядом со Start (нет / 5 / 15 / 30 / 45 / 60 мин) — одна настройка для двух мест:
  при Start поиск показывает совпадения за этот период (без оповещений), а вкладка «Весь чат»
  открывается с сообщениями за этот же период.
- Копирование из ленты и «Весь чат»: выдели мышью и Ctrl+C (работает и на русской раскладке),
  или правый клик — «Копировать», «Копировать сообщение» (строка целиком), «Выделить всё».
- Ширину ленты и списка «Что искать» можно менять, перетаскивая промежуток между ними; ни одна
  часть не становится уже исходной ширины списка. Ширина запоминается (`items_width`).
- Лента совпадений прижата к низу, как игровой чат: новые сообщения внизу.
- Вкладка «Весь чат» — Поиск группы, общий, личные, группа и легион за период «Истории» и дальше
  вживую, пока открыта вкладка. Справа в строке вкладок: «Информация и уведомления» (добыча,
  кинары, ошибки, события — без боевых строк) и «Пауза».
  Ссылки на предметы из каталога окрашены по качеству, как в игре (epic — оранжевый, legend —
  синий…): `<Кожаные перчатки Рудры>`; наведи — появится подсказка с характеристиками.
- Ссылки на место показываются как `<Место · Келькмарос>` (бирюзовым), задания — с названием:
  `<Задание: Уничтожение повстанцев Ривара>` (`data/quest_names.tsv` с kb.aionempire.com/quests,
  обновить: `python tools/list_quests.py`), рецепты и «создает: [предмет]» — названием предмета.
  Смайлы клиент пишет в лог знаками `?` (в кодировке лога смайлов нет, какой был смайл — не узнать),
  поэтому серии `???` (три и больше) из сообщений убираются. Если игра обрезала длинное сообщение посреди
  ссылки, видна её часть с «…».
- **Точки на карте.** Постоянный набор без панели слоёв: привратники, склады, торговцы, «товары за
  монеты», посредники, мастера стигм, почта, артефакты (позже — кибелиски, крепости, входы в данжи).
  Сбор ресурсов, точки заданий и порталы не показываются: порталы из файлов уровня — служебные
  объекты редактора, а не порталы игры (план карты v3, `docs/map-poi-plan.html`). Точки — из файлов
  клиента (`data/maps/poi.json`, `tools/build_poi.py`), иконки только готовые (`tools/build_map_icons.py`),
  крупные, привратники крупнее остальных. Близкие точки одного вида сливаются в значок с числом
  (клик — приблизить). Клик по значку — карточка справа: имя, координаты и «Рядом» — ближайшие
  привратник, склад, торговец, мастер стигм, артефакт с расстоянием в метрах. Поиск сверху находит
  эти точки по имени и типу и районы; Enter — следующий. Внизу карты — игровые координаты под курсором.
  Расстановка в клиенте может отличаться от сервера: часть NPC сервер добавляет сам.
- **Карта** — отдельная вкладка: сверху выбор зоны, карту можно просто листать. Клик по ссылке
  `<Место · Келькмарос>` в чате открывает эту вкладку с меткой места. Управление как у игровой карты: колесо мыши — масштаб к точке под курсором, перетаскивание — сдвиг, двойной клик —
  приблизить; кнопки ⌂ (вся карта), −, +, ◎ (обратно к метке). Бирюзовые точки — другие места,
  которые кидали в «Поиск группы» (наведи — кто и что написал). Есть карты: Келькмарос, Ингисон,
  Тоннель Силентера, Пандемониум, Исхальген, Альтгард, Морхейм, Брустхонин, Белуслан
  (8 зон — карты в игровом стиле с aiondb.ru, `data/maps/aiondb`; Пандемониум пока на радарной карте клиента,
  `data/maps/client`). Привязка координат — по правилу клиента `zonemap.xml`: картинка 3072 px покрывает
  `map_width` игровых метров начиная со смещения `offset_x/offset_y` (без смещения — весь мир); проверено по
  258 NPC aiondb, совпавшим с NPC клиента по номеру, и по 440 точкам Тоннеля Силентера. Точки на карте
  пересчитываются из игровых координат при загрузке. Дополнительно извлечены карты Элтенена, Бертрона и
  Интердики; их привязка пока не подключена. Районы подписаны русскими названиями из `data/maps/labels.tsv`.
  При приближении на картах подписаны районы, лагеря, врата и крепости — официальные русские названия с aiondb.ru
  (`data/maps/labels.tsv`; в Пандемониуме подписей нет — у aiondb он из другой версии игры).
  Из миссионных данных клиента дополнительно собраны координаты 69 231 объекта в 12 зонах, включая точки NPC, сбора, заданий, порталов и 351 точку функциональных NPC. Эти данные пока доступны в таблицах `client_extract/client_level_objects.tsv` и `client_level_entities.tsv`; координаты NPC клиента могут не совпасть с настройками сервера. Для Элтенена, Бертрона и Интердики трансформы пока не подтверждены. Для Арэшурата карты пока нет.
- Поиск ловит и строки «Поиска группы» с битой кодировкой названия канала (`[3.????? ??????]`).
- Наведи на иконку или название предмета в списке — появится подсказка с характеристиками,
  как в игре (данные с kb.aionempire.com).

## config.json

Создаётся рядом с exe / `main.py` при первом запуске.

| Ключ | По умолчанию | Смысл |
|------|--------------|-------|
| `game_dir` | `C:\aMain\Games\AION Imperia\Aion Empire` | папка игры |
| `chat_log` | `""` | полный путь к логу, если он не в `game_dir\classic\Chat.log` |
| `keywords` | `[]` | ключевые слова |
| `watch_items` | `[]` | номера отмеченных предметов |
| `search_mode` | `"or"` | `or` слово или предмет, `words`, `items`, `and` слово и предмет |
| `history_min` | `0` | сколько минут истории проверить при Start |
| `collapsed_groups` | `[]` | свёрнутые секции списка |
| `poll_interval_ms` | `500` | как часто читать лог |
| `cooldown_sec` | `60` | анти-спам для повторов |
| `sound_path` | `""` | WAV оповещения; пусто — системный сигнал |
| `alert_mode` | `"standard"` | `standard` или `nag` (назойливый) |
| `react_sec` | `30` | время на реакцию в назойливом режиме: 15, 30, 60 или 120 с |
| `nag_popup` | `false` | окно поверх игры в назойливом режиме |
| `sound_volume` | `80` | громкость звуков оповещения, % |
| `chat_system` | `false` | «Весь чат»: системные сообщения |
| `filter_grades` | `[]` | список: показываемые качества, пусто — все |
| `filter_level_min` / `filter_level_max` | `0` | список: уровень от / до, 0 — любой |
| `filter_type` | `""` | список: тип («Лата», «Оружие: Меч»), пусто — все |
| `game_check` | `true` | останавливать слежение, если игра не запущена |

## Данные

- `data/item_names.tsv` — каталог «номер → название» (61 тыс. предметов, kb.aionempire.com, RU);
- `data/watch_items.csv` — предметы для списка «Что искать»: `id,name,level,category,grade,icon`;
- `data/icons/<icon>.png` — иконки (одна картинка на несколько предметов с одинаковым видом);
- `data/item_specs.json.gz` — характеристики для подсказок.
- `data/ui/*.png` — картинки скруглённых кнопок, полей, карточек и вкладок. Пересобрать после
  смены цветов или радиуса в `watcher/theme.py`: `python tools/build_ui.py`.

Обновить каталог с сайта (нужен Pillow):

```
python tools/kb_crawl.py downloads/kb_items/all_items_ru.tsv     # список всех предметов
python tools/crawl_items.py downloads/kb_items/all_items_ru.tsv downloads/kb_items/cache/items45.jsonl 45   # страницы предметов
python tools/build_catalog.py cache.jsonl                                  # csv, характеристики, иконки
```

`crawl_items.py` докачивает только недостающее, его можно прерывать. Какие типы брать — `PREFIXES`
в нём (100/101 оружие, 110–114 броня, 115 щиты, 187 крылья). Иконки, которых нет на сайте (404),
заменяются заглушкой.

## Разработка

Нужен Python 3.10+ и Pillow (карты).

```
pip install -r requirements.txt
python -m pytest
python tools/fake_chat.py <тестовый лог> "текст" [ник]   # ручная проверка; не на настоящий Chat.log
build_exe.bat                                            # сборка exe
```
