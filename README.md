# Aion Chat Watcher

Следит за чатом Aion в реальном времени и подаёт звуковой сигнал, когда в канале
«Поиск группы» появляется сообщение с одним из ключевых слов или ссылка на отмеченный предмет.

Программа только читает файл `Chat.log`. Клиент, память игры и ввод не трогаются.

## Как работает

Клиент пишет чат в `<папка игры>\classic\Chat.log` (в `system.cfg` должно быть `g_chatlog = "1"`).
Программа читает только новые строки, берёт строки `[3.Поиск группы]`, отбрасывает ник и служебную
разметку и ищет ключевые слова в тексте (без учёта регистра, «ё» = «е»).
Ссылки на предметы (`[item:ID]`) показываются названием из каталога kb.aionempire.com, поэтому
ключевое слово находит и названия предметов в ссылках.

Справа список «Что искать» — оранжевые (epic) предметы Рудры и Фланаса и Крылья Рудры, с иконками,
по секциям: Лата, Кольчуга, Кожа, Ткань, Оружие, Щиты, Крылья, Прочее. Клик по заголовку секции
сворачивает её, галочка «все» отмечает всю секцию. Отмеченный
предмет срабатывает, если на него кинули ссылку в чат. Сообщение подходит, если совпал отмеченный
предмет **или** ключевое слово; если ничего не отмечено — ищется только по ключевым словам.

Один и тот же текст от того же игрока не звенит чаще раза в `cooldown_sec` секунд.

## Запуск

- `AionChatWatcher.exe` — или из исходников: `python main.py`.
- «Папка игры» — папка `Aion Empire` (поле само показывает полный путь к `classic\Chat.log`;
  можно вставить и прямой путь к любому `Chat.log`). Справа статус: «● Слежу», «○ Не слежу»,
  «⚠ Chat.log не найден». «Обзор…» открывает выбор папки.
- «Ключевые слова» — через запятую, применяются по Enter. Справа — режим поиска:
  - «Слово ИЛИ предмет» (по умолчанию) — совпало слово **или** ссылка на отмеченный предмет;
  - «Только слова» — галочки предметов не учитываются;
  - «Только предметы» — ключевые слова не учитываются;
  - «Слово И предмет» — нужно и слово, и ссылка на отмеченный предмет в одном сообщении.
  Если для режима чего-то не хватает, статус подскажет («нет ключевых слов», «не отмечены предметы»).
- Start / Stop. Сигналы только для новых сообщений после Start.
- «Оповещение»:
  - режим **Стандартный** — один звук на пачку совпадений;
  - режим **Назойливый** (как будильник) — звук по кругу, мигает кнопка на панели задач, а в ленте
    мигает полоса с найденным сообщением и галочкой «принять». Сигнал звучит, пока есть непринятые строки;
  - «Реакция» (15 / 30 / 60 с / 2 мин, по умолчанию 30 с) — строка, которую не приняли за это
    время, считается пропущенной;
  - «Окно поверх игры» — дополнительно показывать окно «Найдено в чате» поверх всех окон (наведение,
    клик или ОК принимают все строки). В эксклюзивном полноэкранном режиме игры оно не видно;
  - «Громкость» — ползунок громкости звуков оповещения (0–100 %, только звуки этой программы);
  - над лентой всегда видны счётчики «Найдено / Отреагировал / Пропущено» (счёт за текущий
    запуск, «Сбросить» обнуляет);
  - «Звук» — системный сигнал, звуки Windows (Alarm, Ring…) или «Свой файл…» (WAV); ▶ — прослушать.
- «История» рядом со Start (нет / 5 / 15 / 30 / 45 / 60 мин) — одна настройка для двух мест:
  при Start поиск показывает совпадения за этот период (без оповещений), а вкладка «Весь чат»
  открывается с сообщениями за этот же период.
- Лента совпадений прижата к низу, как игровой чат: новые сообщения внизу.
- Вкладка «Весь чат» — Поиск группы, общий, личные, группа и легион за период «Истории» и дальше
  вживую, пока открыта вкладка. Справа в строке вкладок: «Информация и уведомления» (добыча,
  кинары, ошибки, события — без боевых строк) и «Пауза».
  Ссылки на предметы Рудры (и всё из списка «Что искать») выделены оранжевым, как в игре:
  `<Кожаные перчатки Рудры>`; наведи — появится подсказка с характеристиками.
- Поиск ловит и строки «Поиска группы» с битой кодировкой названия канала (`[3.????? ??????]`).
- Наведи на иконку или название предмета в списке — появится подсказка с характеристиками,
  как в игре (данные с kb.aionempire.com).

## config.json

Создаётся рядом с exe / `main.py` при первом запуске.

| Ключ | По умолчанию | Смысл |
|------|--------------|-------|
| `game_dir` | `C:\aMain\Games\AION Imperia\Aion Empire` | папка игры |
| `chat_log` | `""` | полный путь к логу, если он не в `game_dir\classic\Chat.log` |
| `keywords` | `[]` | ключевые слова |
| `watch_items` | `[]` | номера отмеченных предметов |
| `search_mode` | `"or"` | `or` слово или предмет, `words`, `items`, `and` слово и предмет |
| `history_min` | `0` | сколько минут истории проверить при Start |
| `collapsed_groups` | `[]` | свёрнутые секции списка |
| `poll_interval_ms` | `500` | как часто читать лог |
| `cooldown_sec` | `60` | анти-спам для повторов |
| `sound_path` | `""` | WAV оповещения; пусто — системный сигнал |
| `alert_mode` | `"standard"` | `standard` или `nag` (назойливый) |
| `react_sec` | `30` | время на реакцию в назойливом режиме: 15, 30, 60 или 120 с |
| `nag_popup` | `false` | окно поверх игры в назойливом режиме |
| `sound_volume` | `80` | громкость звуков оповещения, % |
| `chat_system` | `false` | «Весь чат»: системные сообщения |

## Данные

- `data/item_names.tsv` — каталог «номер → название» (61 тыс. предметов, kb.aionempire.com, RU);
- `data/watch_items.csv` — предметы для списка «Что искать» и их секции (`category`);
- `data/icons/<id>.png` — их иконки;
- `data/item_specs.json` — характеристики для подсказок.
- `data/ui/*.png` — картинки скруглённых кнопок, полей, карточек и вкладок. Пересобрать после
  смены цветов или радиуса в `watcher/theme.py`: `python tools/build_ui.py`.

Добавить предмет: дописать строку `id,название,уровень` в `data/watch_items.csv` и запустить
`python tools/build_specs.py` — он скачает характеристики, иконку и проставит секцию.
У Крыльев Рудры на сайте нет иконки (404), вместо неё показывается заглушка.

## Разработка

Нужен Python 3.10+.

```
pip install -r requirements.txt
python -m pytest
python tools/fake_chat.py <тестовый лог> "текст" [ник]   # ручная проверка; не на настоящий Chat.log
build_exe.bat                                            # сборка exe
```
