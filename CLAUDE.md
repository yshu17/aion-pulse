# Для Claude

Работаем в паре с Кодексом. Перед любой работой прочитай `PAIR.md` (правила, задачи, журнал), после работы
допиши туда строку в журнал и обнови статус шага в `docs/map-poi-plan.html`.

## Экономия лимитов

Простые задачи (поиск по коду, grep, правка одного файла, переименование, поиск места в тексте) отдавай
субагенту `Agent` с `model: "haiku"`. Архитектура, отладка, сложные правки, проверка тестов и решения
остаются на основной модели. Субагент не видит контекст диалога: промпт пиши полностью (пути, что найти, что вернуть).

## Доказательства по задаче

Каждую закрытую задачу сопровождай записью в `docs/plan-evidence.json` (правило 16 в `PAIR.md`): снимки «до» и «после»
(`tools/evidence_shots.py`), краткий результат и `skills_used` — только скиллы, реально вызванные через Skill. Не писать
рекомендованный скилл как использованный.
