# UI/UX: аудит и план визуального обновления — Aion Chat Watcher

Дата аудита: 09.10.2026. Состояние кода: коммит `7e6fc87` (ветка, в которой ведётся проект). Это **план**.
Ниже он согласован с актуальным планом карты v3 в [`docs/map-poi-plan.html`](docs/map-poi-plan.html): решения по
составу карты, источникам данных и статусам карты берутся оттуда. Снимки и замечания аудита описывают состояние
на момент аудита и перед реализацией сверяются с текущим интерфейсом.

## 0. Как проводился аудит

**Изученные дизайн-скиллы** (`.claude/skills/`):

| Скилл | Что взято | Что сознательно не взято |

Генератор `--design-system` для «gaming companion desktop utility dark» выдал стиль **Dark Mode (OLED)** — он совпадает с текущим направлением | паттерн «Scroll-Triggered Storytelling», шрифты Cinzel/Josefin и фиолетовая палитра из генератора — они для веб-лендингов, к настольной утилите не подходят |
| `high-end-visual-design` | мягкая глубина без грубых теней, «внутренняя подсветка» верхней кромки карточек, тонкие волосяные границы, кривые ускорения вместо линейных, анимировать только дешёвые свойства, дисциплина слоёв | «двойной безель», огромные отступы `py-24+`, стеклянные размытия, пилюли-CTA с кнопкой-в-кнопке, scroll-reveal — для плотной Tk-утилиты, которую держат рядом с игрой, это шум и лишняя нагрузка (скилл сам предупреждает: не для плотных дашбордов) |
| `design-theme-guide` | тема как **реестр токенов**, а не набор экранов; у каждой текстовой пары — измеренный контраст и уровень WCAG; шкала отступов 4/8 pt; один источник значений | CSV/SQL/Notion-выгрузки — проекту не нужны |
| `ui-visual-validator` | метод: сначала описать то, что видно на скриншоте, искать доказательства провала, не принимать «стало иначе» за «стало лучше»; контроль через сравнение скриншотов | инструменты для веба (Chromatic, Percy, Playwright) — у нас Tk |

**Что проверено на реальном интерфейсе.** Приложение запускалось из исходников с копией пользовательского
`config.json` (проверка игры выключена, звук заглушён), снимки окон сделаны через WinAPI `PrintWindow`
(игра была запущена поверх). Снято: стартовое окно, «Поиск» с историей за 60 мин, «Весь чат», «Карта» (общий вид
и приближение), окно на минимальном размере 1000×600, окно «Найдено в чате!» (назойливый режим), подсказка
предмета, попытка показать фокус клавиатуры. Контраст всех основных пар цветов посчитан по формуле WCAG 2.x.

**Что не проверено** (выводы по этим пунктам — гипотезы, отмечены «не проверено»):
- фокус с клавиатуры: окно на снимке не было активным в Windows, поэтому отсутствие рамки фокуса может быть
  артефактом съёмки;
- масштаб Windows 125/150 % (тестировался только 100 %, экран 2560×1440);
- Windows 10 (шрифт Segoe UI Variable есть только в Windows 11);
- реальная плавность анимаций Tk на слабом ПК рядом с запущенной игрой.

## 1. Текущее состояние

### Стек и архитектура интерфейса
- Python 3.14, **tkinter / ttk на Tk 9.0.4**, тема `clam`, переопределённая в `watcher/theme.py`.
- Скругления — 9-slice PNG из `data/ui/` (рисует `tools/build_ui.py`), углы закрашены цветом фона позади.
- Окно (`watcher/app.py`): шапка с заголовком и счётчиками → 3 строки настроек → строка Start / История →
  `ttk.Notebook` с вкладками **Поиск** (`watcher/feed.py` + `watcher/itemlist.py` через `tk.PanedWindow`),
  **Весь чат** (`watcher/allchat.py`), **Карта** (`watcher/mapview.py` + `watcher/mapcard.py`).
- Всплывающие окна: «Найдено в чате!» (`watcher/alarm.py`), подсказка предмета (`watcher/tooltip.py`),
  контекстное меню копирования (`watcher/textview.py`).
- Текст чата — `tk.Text` с тегами; список предметов и карта — `tk.Canvas` (виртуальная отрисовка).
- Тесты (`tests/`, 213) проверяют в том числе тексты статусов, имена стилей и расположение виджетов
  (`counters_bar.master is header`, `item_controls` и т. п.).

### Сильные стороны (сохранить)
- Цельная тёмная тема с одним тёплым акцентом `#ff8c1a` — узнаваемо, «по-айоновски» (цвет эпического предмета).
- Отличная читаемость основного текста: `TEXT` на фоне — **14.8:1**, на карточке — **13.5:1**.
- Цвета качества предметов как в игре + подсказка предмета в игровом стиле (`tooltip.py`) — сильная сторона,
  её стоит сделать образцом для остальных всплывающих элементов.
- Ник выделен отдельным цветом (`#9cc4ff`, 9.3:1), время приглушено — ясная структура строки чата.
- Скруглённые 9-slice-элементы, тёмный заголовок окна Windows (`dark_title_bar`), понятные подписи по-русски.
- Виртуальные списки на Canvas — быстрые при 27 тыс. предметов.

качество приложения. UI-задачи не меняют состав точек и источники данных, а карта не считается готовой только
потому, что завершена её визуальная полировка.

- Пункт 18 таблицы ниже (порядок кнопок, пустая подпись, размер области карты) основан на снимках аудита, сделанных
  до упрощения карты v3. Перед реализацией повторно осмотреть текущую вкладку: закрыть пункт, если проблема уже
  устранена, и оставить только подтверждённые дефекты.
- Пункт 30 (плавное перемещение к результату поиска) — необязательная полировка. Он не должен менять поведение

- UI-этапы, не связанные с картой, можно выполнять независимо. Работы над видом карты идут после подтверждения

### Основные проблемы (по снимкам)
1. **Настройки съедают экран.** Шапка и три строки настроек занимают ≈ 400 px из 860 (≈ 45 % высоты), хотя
   меняются редко. Лента совпадений и список предметов получают меньше половины окна.
2. **На минимальном размере 1000×600 интерфейс ломается:** строка «Оповещение» обрезана («Гро…»), громкость не
   видна, лента сжата до ~200 px.
3. **Оранжевый перегружен смыслами.** Одним цветом обозначены: главная кнопка Start, активная вкладка, заголовки
   карточек («Что искать»), отмеченные чекбоксы, совпадения в чате (сплошная заливка), эпическое качество
   предметов и стрелки выпадающих списков. Акцент перестаёт быть сигналом.
4. **Совпадения в чате — тяжёлые сплошные плашки.** Заливка `#ff8c1a` во всю высоту строки; соседние плашки
   сливаются («WTS<Боевой молот Рудры>» — одна оранжевая полоса), текст внутри читать труднее, чем вокруг.
5. **Счётчики выглядят как кнопки.** «Найдено / Отреагировал / Пропущено» оформлены так же, как кнопка
   «Сбросить» рядом — непонятно, что нажимается.
6. **Статус слежения малозаметен:** «● Слежу» — мелкий текст в конце строки пути к логу, далеко от кнопки Start.
7. **Иконки — набор разнородных символов Юникода** (▶ ▲ ▼ ✕ ⌂ ◎ − + ★ ✓ ● ○ ⚠ ▸ ▾) из разных шрифтов, разной
   толщины и оптического размера; `◎` (вернуться к метке) непонятен без подписи. В заголовке окна —
   стандартное перо Tk вместо значка программы.
8. **Вкладки не выровнены:** у выбранной вкладки подпись выше на ~4 px, чем у остальных (видно на всех снимках).
9. **Нет состояний «пусто» и «загрузка».** До Start лента — пустой тёмный прямоугольник; при Start с историей
   за 60 мин программа читает лог (255 МБ у пользователя) без индикатора.
10. **Контраст ниже нормы** у нескольких пар:
    | Пара | Контраст | Норма | Где |
    |---|---|---|---|
    | `DISABLED #5c606a` / `SURFACE` | 2.65 | 4.5 | выключенные фишки качества («Легенд.»), отключённые поля |
    | `DANGER #e5484d` / `SURFACE_2` | 3.72 | 4.5 | счётчик «Пропущено» |
    | белый / `DANGER` | 3.91 | 4.5 | кнопка Stop (13 pt bold — ещё не «крупный текст» по WCAG) |
    | `BORDER #363a45` / фон | 1.5–1.6 | 3.0 (граница компонента) | контуры полей и карточек |
11. **Выключенная фишка фильтра выглядит как недоступная** («Легенд.» серая) — «выключено» и «недоступно»
    неразличимы.
12. **Дублирование стилей вне темы:** 25 жёстко прописанных цветов в `feed.py`, `allchat.py`, `tooltip.py`,
    `mapview.py`, `alarm.py`, `textview.py`, `itemlist.py`; 14 шрифтов задано через `FONT_SIZE ± n` на месте.
    Токенов отступов и типографики нет.
13. **Окно «Найдено в чате!»** для одного сообщения занимает 710×480: ~70 % — пустая область; рамка-«мигалка»
    коричневая и тусклая на фоне.
14. **Карта:** кнопки масштаба идут справа налево «⌂ − + ◎» в обратном привычному порядке; между полем поиска и
    подсказкой виден лишний узкий прямоугольник (пустая подпись `self.title` со стилем карточки на фоне окна);
    при «показать всё» карта занимает лишь середину области.
15. **Полосы прокрутки** — классические, широкие, со стрелками и «рёбрами» на ползунке; выбиваются из
    современного вида.
16. **Ползунок громкости** — ползунок с полосками, по виду не похож на остальные контролы.

### Технические ограничения и возможности Tk
- Нет CSS, теней, прозрачности виджетов, размытия и трансформаций. Глубина достигается только цветом
  поверхностей и картинками (9-slice). Прозрачность есть только у **окна целиком** (`-alpha`).
- Анимация — только покадрово через `after()`: смена цвета тега/фона, `-alpha` окна, перерисовка Canvas.
  Дёшево для нескольких элементов; дорого для карты (перемасштабирование изображения PIL).
- Шрифты — только установленные в системе (или подключённые через `AddFontResourceEx` с флагом `FR_PRIVATE`).
  OpenType-фичи (табличные цифры) недоступны.
- Иконки — PNG (`PhotoImage`), рендерить SVG нужно заранее инструментом (в проекте уже есть путь через
  headless Chrome в `tools/build_map_icons.py`).
- Tk 9 рисует любые символы Юникода, но цветные эмодзи на Windows — не проверено и непредсказуемо.

## 2. Целевая дизайн-концепция

### Направление: «Тихая панель, громкий сигнал»
Программа живёт рядом с игрой и большую часть времени **ждёт**. Интерфейс должен быть спокойным и тёмным,
а единственное, что «кричит», — найденное совпадение и действие пользователя. Сохраняем айоновский тёплый
акцент и игровые цвета качества, убираем визуальный шум и даём ленте место.

**Принципы**
1. **Сигнал важнее декора.** Оранжевый — только для: главного действия (Start), живых совпадений, выбранного.
2. **Контент первым.** Настройки, которые меняют раз в неделю, — в сворачиваемую панель; лента и список — на весь
   экран.
3. **Состояние видно всегда.** Слежу / не слежу / игра не запущена / ошибка — крупный индикатор рядом со Start.
4. **Один язык компонентов.** Каждая кнопка, поле, фишка, вкладка — из одного набора токенов и картинок.
5. **Игровое — там, где игровое.** Цвета качества, подсказка предмета, значки карты — как в игре; рамка программы
   — нейтральная современная.
6. **Движение только со смыслом**, короткое (120–250 мс), отключаемое.

к тому же Segoe UI Variable лучше выглядит в Windows и хорошо держит кириллицу.

| Токен | Кегль (pt Tk) | Начертание | Где |
|---|---|---|---|
| `type.display` | 18 | Semibold | название программы |
| `type.title` | 14 | Semibold | заголовки карточек, окно «Найдено в чате» |
| `type.body` | 13 | Regular | лента, весь чат (оставить — читают «краем глаза») |
| `type.control` | 12 | Regular / Semibold для главных кнопок | кнопки, поля, вкладки |
| `type.caption` | 11 | Regular | подписи полей, уровни, подсказки |
| `type.micro` | 10 | Semibold | фишки качества, бейджи |
| `type.mono` | 11 | Cascadia Mono / Consolas | время в ленте и во «Всём чате» |

Межстрочный интервал ленты сохранить (`spacing1/3 = 4`), длинные строки — без ограничения ширины (это чат).

### Отступы, скругления, поверхности
- **Шкала отступов 4 pt:** `space.1=4`, `space.2=8`, `space.3=12`, `space.4=16`, `space.6=24`, `space.8=32`.
  Внутри карточки — 12–16; между карточками — 12; поля окна — 16.
- **Скругления:** `radius.control = 8` (кнопки, поля, вкладки), `radius.card = 12`, `radius.pill = половина
  высоты` (фишки, бейджи, счётчики). Сейчас 9/12 — свести к 8/12.
- **Поверхности и «глубина» без теней:** фон окна → карточка (на 1 тон светлее) → поле/кнопка (ещё на тон).
  В 9-slice-картинки карточек и кнопок добавить **1 px светлую верхнюю кромку** (`#ffffff` 4–6 %) — приём
  «внутренней подсветки» из `high-end-visual-design`, единственная «тень», доступная в Tk.
- **Границы:** только `border.control` у интерактивного и `border.subtle` у разделителей; никаких серых рамок
  вокруг всего подряд.

### Иконки
- Один набор: **Phosphor Icons, начертание Regular** (MIT) — тонкий, но читаемый на 16–20 px, есть все нужные
  метафоры (play, caret-up/down, x, house, crosshair, magnifying-glass, gear, star, check, warning, bell).
  Lucide допустим как запасной вариант, но не смешивать.
- Готовые SVG рендерятся в PNG инструментом (по образцу `tools/build_map_icons.py`) в `data/ui/icons/`:
  размеры 16 и 20 px, цвета `text.secondary`, `text.primary`, `accent`, `on.accent`.
- Значки карты и предметов **не трогаем** — они игровые (правило проекта: только готовые, из клиента или aiondb).
- Значок окна и панели задач — готовый (значок клиента Aion из папки игры или Phosphor `chat-circle-dots`),
  вместо пера Tk.
- Эмодзи — **нет**. Ни в интерфейсе, ни в статусах: на Windows в Tk они непредсказуемы, а скилл `ui-ux-pro-max`
  прямо запрещает эмодзи вместо иконок. Символы Юникода в тексте статусов заменить иконками.

### Анимации (принципы)
- Длительность 120–250 мс, кривая «быстрый старт, мягкая остановка» (ease-out cubic), шаг кадра 16–33 мс.
- Анимируем только дешёвое: цвет тега/фона, `-alpha` окна, перерисовку нескольких элементов Canvas.
  Карту (перемасштабирование PIL) не анимируем, кроме коротких проверенных случаев.
- Один общий модуль `watcher/motion.py` (`tween_color`, `fade_window`, `pulse`), чтобы не плодить `after()`.
- Учитываем системную настройку Windows «Показывать анимацию» (`SPI_GETCLIENTAREAANIMATION`) и флаг
  `reduce_motion` в `config.json`: если выключено — состояния меняются мгновенно.

## 5. Единая дизайн-система

**Где живёт:** один модуль `watcher/theme.py` + картинки `data/ui/` (генерирует `tools/build_ui.py`) + иконки
`data/ui/icons/` (генерирует `tools/build_ui_icons.py`). Никаких цветов и шрифтов в других модулях.

**Токены** (именованные константы/словари в `theme.py`):
- `COLOR` — семантика из раздела 2 (`bg.*`, `text.*`, `border.*`, `accent*`, `focus`, `success`, `warning`,
  `danger`, `info.place`, `nick`, `grade.*`, служебные `pending/accepted/missed` для ленты).
- `TYPE` — `display`, `title`, `body`, `control`, `caption`, `micro`, `mono` → готовые кортежи шрифтов.
- `SPACE` — 4, 8, 12, 16, 24, 32. `RADIUS` — `control 8`, `card 12`, `pill`.
- `MOTION` — `fast 120`, `base 200`, `slow 1200` (подсветка новой строки), `pulse 2000`, кривая ease-out.

**Стили ttk (имена — контракт для кода):** `Primary.TButton`, `TButton` (обычная), `Ghost.TButton`,
`Danger.TButton`, `Icon.TButton`; `TEntry`/`Card.TEntry`; `TCombobox`/`Card.TCombobox`; `Chip` (фишка: off/on/
disabled); `Stat.TLabel` (счётчик); `StatusChip`; `Card.TFrame`; `Section.TLabel` (заголовок карточки);
`Caption.TLabel`; `Item.TCheckbutton`; тонкие `Vertical.TScrollbar`; `TNotebook.Tab`.

**Общие помощники:** `theme.style_text()` (теги ленты: `meta`, `nick`, `hit`, `new`, `note`), `motion.py`
(анимации), `hint.py` (подсказки), `theme.icon(name, size, color)` (загрузка PNG-иконки с кэшем).

**Правила:** новый цвет — только новой строкой в `COLOR` с контрастом; новый компонент — из существующих стилей;
символы Юникода как иконки запрещены (проверка тестом по списку символов).

## 6. Риски и ограничения

| Риск | Влияние | Как снизить |
|---|---|---|
| Тесты завязаны на тексты статусов, имена стилей и расположение виджетов (`counters_bar.master is header`, `"○ Не слежу"`) | этапы 3–5 «сломают» тесты без изменения поведения | менять тесты в том же коммите; проверять поведение, а не пиксели; тексты статусов оставить прежними |
| Tk не умеет тени, размытие, прозрачность виджетов | часть «премиальных» приёмов невозможна | глубина цветом и 9-slice; не имитировать стекло |
| Анимации через `after()` рядом с игрой | лишняя нагрузка CPU | только короткие, только на несколько элементов, общий таймер, отключение; карту не анимировать |
| Segoe UI Variable нет в Windows 10 | другой вид шрифта | откат на Segoe UI, проверка на Win10 (этап 8) |
| DPI 125/150 % | размытые/мелкие картинки | DPI-awareness + картинки @2x, проверка (этап 8) |
| Перестройка шапки меняет привычное расположение | пользователь ищет настройки | настройки открыты по умолчанию при первом запуске, состояние запоминается |
| Иконки Phosphor — внешний набор | лицензия, вес exe | MIT; в exe только нужные 20–30 PNG (≈ 30 КБ) |
| Цвета качества совпадают с акцентом (epic = accent) | смешение смыслов | акцент не для текста заголовков; выбор — фоном/рамкой, а не только цветом текста |
| Одновременная работа с Кодексом | конфликт правок `theme.py`/`app.py` | задачи в `PAIR.md`, по одному этапу за раз |

Бизнес-логика (поиск, оповещения, серии, лог, карта и её данные), формат `config.json` (кроме новых
необязательных ключей `settings_open`, `reduce_motion`) и сценарии пользователя не меняются.

## 7. Критерии готовности

1. **Снимки «до/после»** всех экранов (`docs/ui/before`, `docs/ui/after`) — разница соответствует плану,
   регрессий нет (проверка по методу `ui-visual-validator`: описать видимое, искать провалы).
2. **Контраст:** все пары «текст/фон» ≥ 4.5:1, контуры интерактивных элементов ≥ 3:1 — значения записаны
   рядом с токенами.
3. **Нет жёстких цветов и шрифтов** вне `watcher/theme.py` (тест).
4. **Нет символов-иконок Юникода** в интерфейсе; все иконки из одного набора, размеры 16/20 px.
5. **Минимальное окно 1000×600:** ни один элемент не обрезан; при 1400×860 лента и список занимают ≥ 60 %
   высоты окна.
6. **Состояния:** у ленты, «Всего чата» и карты есть «пусто», у Start с историей — «загрузка», у ошибок — баннер
   с действием.
7. **Фокус:** проход Tab по всем контролам в активном окне показывает видимое кольцо `focus`.
8. **Анимации** ≤ 250 мс (кроме пульса и подсветки новой строки), отключаются системной настройкой и флагом.
9. **Проверено** на 100/125/150 % масштабе и (если есть возможность) на Windows 10.
10. Все тесты проходят, exe собирается, размер exe вырос не больше чем на 1 МБ.

## С чего начинать

С **этапов 0–1** (снимки «до» + реестр токенов, пункты 2 и 5): это дешёво, ничего не меняет внешне ради самого
изменения, сразу закрывает P0 по контрасту и делает все дальнейшие этапы безопасными — каждая следующая правка
пойдёт через токены и будет проверяться снимками. Пункт 1 (обрезка на 1000×600) — однострочная правка
`minsize`, её можно сделать сразу вместе с этапом 1 как временную меру до новой компоновки (этап 5).
