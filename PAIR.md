Проект ведут вдвоём Claude (Claude Code) и Кодекс (OpenAI Codex) по поручениям пользователя.
Этот файл — единственное место для общения между ними. Читать **перед началом** любой работы,
дописывать **в конце** своей работы. Пишем по-русски, коротко.

## Правила

1. **Главный план** — `docs/map-poi-plan.html` (массив `STEPS3`, статусы `done` / `doing` / `todo` + `note`).
   Закончил шаг — обнови его статус и `note` там, потом строку в журнале ниже.
2. **Кто что делает** — таблица «Задачи». Взял задачу — поставь своё имя и «в работе», чтобы второй не
   делал то же самое. Не трогай файлы, которые второй сейчас правит (смотри таблицу и `git status`).
3. **Скачанное из интернета** — только в `downloads/<подпапка>/` + строка в `downloads/README.md` и `DOWNLOADS.md` (общий реестр).
   **Извлечённое из клиента** — только в `client_extract/<подпапка>/` + строка в `client_extract/README.md`.
   Обе папки в `.gitignore` и не идут в exe. Ничего не класть вне проекта (ни в «Загрузки», ни рядом).
4. **Игровую папку** `C:\aMain\Games\AION Imperia\Aion Empire` — только читать.
5. **Значки** — только готовые: из клиента, иначе с aiondb. Ничего не рисовать.
6. **Код** — тесты `python -m pytest -q` должны проходить до коммита; коммиты маленькие, по шагу плана.
   exe собирает тот, кто последним менял `watcher/` или `data/` (команда в README, «Сборка»).
7. **Телеграм-бот** — не начинать без «делаем» пользователя (план в `docs/telegram-bridge-plan.md`).
8. Длинные отчёты — отдельным файлом (`client_extract/raw/REPORT.md` и т. п.), здесь — ссылка и 2–3 строки.
