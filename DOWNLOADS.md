# Загрузки и внешние файлы проекта

Реестр для Кодекса и Claude: какие внешние файлы нужны проекту и где они лежат. Перед повторной загрузкой
свериться с ним и с `PAIR.md`.

## Правило для новых загрузок

- Загружать только внутрь проекта; не в системные временные папки, не в «Загрузки», не в папку игры.
- Скачанное из интернета — в `downloads/<подпапка>/`, подробности в `downloads/README.md`.
- Извлечённое из клиента игры — в `client_extract/<подпапка>/`, подробности в `client_extract/README.md`.
- Файлы, которые читает сама программа, — в `data/` (идут в exe), собираются инструментами `tools/` из двух
  папок выше.
- Временные инструменты и архивы — в `tmp/` (в `.gitignore`); после работы удалить и отметить ниже.
- Для каждой загрузки — строка в таблице: путь, источник, назначение, статус. Статус **нужно для работы** —
  файл используется программой или нужен следующему шагу плана; **временное** — удалить после операции.
