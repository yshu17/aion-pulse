Проблемы прошлой версии

Расстановка NPC не проверена после переделкиПривратники и остальные NPC теперь только из npc_info клиента (372). Сервер может ставить NPC иначе — проверить в игре; для точной сверки нужны ссылки «Место» у реальных NPC.
Задания: часть пропущена324 связи «задание → NPC» с aiondb отброшены: NPC не расставлен в файлах клиента; задания Исхальгена и других ранних зон в версии 5.5 отключены — у них нет NPC на aiondb. Связи с aiondb — не файлы игры; отключаются галочкой «Задания».
Входы в данжи — не все15 входов из npc_info клиента на карте. Входов, которых нет в npc_info (например Харамель в Исхальгене), пока нет — Кодекс сверит.
ПандемониумПривязка сверена по точкам клиента, но не по твоим «Местам» в игре.
Келькмарос и ИнгисонОдинаковое число складов (11), торговцев (24), «товаров за монеты» (22) — похоже на зеркальные крепости, проверить в игре.
МелочиЗначок артефакта мелкий (в исходнике мало пикселей); у кибелисков нет собственных имён (в игре тоже); в Тоннеле Силентера в файлах игры нет функциональных NPC. Сбор и задания (≈11,8 тыс. точек) ещё лежат в poi.json, хотя не показываются.
