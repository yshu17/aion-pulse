Решения

Источник данныхКлиент игры (точнее всего для твоего клиента); aiondb — только добор пробелов, позже и по желанию
ИконкиТолько готовые, ничего не рисуем: сначала родные из клиента, недостающие (значки NPC, если их нет в ui.pak) — готовые игровые иконки с aiondb
СлоиФункциональные NPC (по типам) · порталы · крепости и артефакты · входы · сбор (по виду ресурса) · задания · места из чата

Риски

Расстановка в файлах клиента — редакторская: сервер может ставить NPC иначе и добавлять своих (пробелы — шаг 7).
В клиенте есть контент новее 2.0 (Тиамаранта и др.) — на 9 зонах почти не сказывается, лишнее скрывается фильтром.
Сбор — 11 тысяч точек: группировка в кружки с числом обязательна.
В Пандемониуме нет подписей районов (с aiondb не совпали) — можно попробовать названия из строк клиента.
