# Перенос твоих отметок — пошагово

Ничего не переносится само. Старые данные браузера не удаляются ни на одном шаге. Если что-то пошло не так — см. раздел «Восстановление».

Важно: отметки привязаны к адресу страницы. Файл с диска, локальный сервер и артефакт на claude.ai — разные хранилища. Делай всё на том адресе, где ты обычно отмечаешь задачи.

## Шаг 0. Запомни, сколько отмечено сейчас
1. Открой страницу плана UI/UX с добавкой `?native=1` в адрес (например `ui-ux-improvement-plan.html?native=1`). Это старый список.
2. В старом списке посмотри строку прогресса («Выполнено N из M») и запиши число N.
3. То же для страницы Telegram: `telegram-bridge-plan.html?native=1`. Запиши число.

## Шаг 1. Сохрани файл экспорта
1. Открой обычную страницу UI/UX (без `?native=1`).
2. Нажми на строку «Общие задачи пяти планов», чтобы раскрыть панель.
3. Нажми кнопку «Экспорт». Браузер скачает файл. Не удаляй его.
4. Повтори на странице Telegram.

## Шаг 2. Перенеси отметки
1. На странице UI/UX в раскрытой панели нажми «Перенести старые отметки».
2. Появится окно со списком. Строка вверху говорит, сколько отметок переносится.
3. Если есть «конфликты» (старый список и общий журнал показывают разное): у каждого по умолчанию выбрано «оставить как в общем журнале». Ничего не меняй, если не уверен.
4. Нажми «Скачать экспорт» в этом окне — ещё одна копия.
5. Поставь галочку «резервная копия сохранена». Пока галочки нет, кнопка «Перенести» серая.
6. Нажми «Перенести».
7. Повтори шаги 1–6 на странице Telegram.

## Шаг 3. Проверь количество
1. На странице UI/UX в панели выбери фильтр статуса «Выполнено».
2. Прочитай строку «Показано N из M». N должно быть не меньше числа из шага 0 (в нём могут быть и задачи, отмеченные раньше).
3. Снова нажми «Перенести старые отметки». Должно появиться «Переносить нечего» — значит всё уже перенесено. Закрой окно.
4. То же для Telegram.

## Восстановление (если число не сошлось или что-то пропало)
1. Нажми «Откатить» (в той же панели). Состояние вернётся к тому, каким было перед последним переносом.
2. Если не помогло: «Импорт» → выбери файл экспорта из шага 1.
3. Старый список всегда доступен: адрес с `?native=1`.

## Чего не делать
- Не нажимай «Сбросить мои отметки»: это очищает отметки плана.
- Не чисти данные сайта в браузере, пока не убедился, что число сошлось.
- Старые списки пока не удаляются. Удаление (этап 4) — только по твоему отдельному решению после финальной проверки.

## Что дальше
Когда напишешь «перенёс, сошлось» (или опишешь расхождение), я подготовлю финальную проверку перед удалением старых списков. Удаление сам не выполню.
