# Дизайн-система планов (единый стандарт, 12.10.2026)

## 1. Архитектура: один компонент, одно место правки

- **Один источник данных:** `docs/plan-model.json`, собирается `tools/build_master_plan.py`.
- **Одна карточка задачи:** `tools/plan_shared.py` (CSS, разметка, JavaScript). Все пять основных планов, MASTER PLAN
  и шесть подпланов-черновиков получают её инъекцией `inject_shared_explorer`, тем же кодом.
- **Один словарь состояний:** `tools/plan_states.py` (статусы, приоритеты, правило чекбокса, прогресс).
  JavaScript получает словарь из модели, а не держит свой.
- **Общие фильтры и навигация:** `tools/plan_ai_view.py` (фильтры по исполнителю и Skills), `tools/plan_common.py` (панель ссылок).

Проверено 12.10.2026 (тестовое изменение, затем откат, см. журнал `PAIR.md`): изменение одного элемента общей карточки
появилось во всех 12 страницах — пять планов, MASTER PLAN, обзор черновиков и шесть подпланов.

## 2. Карточка задачи (общая структура)

Сворачиваемая строка:
- чекбокс (отметка выполнения);
- ID;
- название;
- бейдж NEW (только у последней открытой задачи);
- приоритет (`Не определён`, если нет);
- иконка/метка исполнителя (Claude, Codex, совместно);
- статус (выпадающий список; «Выполнено» выставляется только отметкой).

Раскрытое содержание:
- описание;
- исполнитель и проверяющий;
- дата создания и дата изменения;
- зависимости;
- критерии готовности;
- блок «AI Tools & Skills»: основной и дополнительные Skills, назначение, исполнитель, проверяющий;
- история изменений (с датой и источником записи).

Для простых задач неприменимые разделы скрываются. Для задачи без значения показывается «Не определено» или
раздел не выводится (единое правило, без пустых декоративных блоков).

## 3. Типографика, отступы, цвета

- Цвета статусов: `planned` серый, `research` синий, `doing` оранжевый, `blocked` красный, `review` жёлтый,
  `done` зелёный, `deferred` фиолетовый, `cancelled` приглушённый серый. Источник — `plan_states.STATES`.
- Контраст цветов статусов и подтверждения проверен тестом (не менее 4,5:1 на обоих фонах), см. раздел 6.
- Радиусы, отступы и шрифт карточек берутся из общего блока `STYLE` в `plan_shared.py`. Новых значений в отдельных планах нет.

## 4. Интерактивность

- Сворачивание каждой задачи; вложенные разделы через `children` (родитель → дочерние).
- Развернуть всё / свернуть всё.
- Поиск по ID, названию, тексту и исполнителю.
- Фильтры: план, статус, приоритет, исполнитель, Skill (набор состояний — из `plan_states.STATES`).
- Экспорт и импорт личных отметок (JSON) — для переноса между браузерами.
- Личные отметки хранятся в браузере (`localStorage`). В MASTER и на страницах они общие для одного браузера.

## 5. Motion Design (сделано, по контракту `application-motion-designer`)

Токены в `tools/plan_shared.py` (`MOTION`): быстрый переход 120 мс, раскрытие 160 мс, закрытие 140 мс, вспышка статуса 600 мс.

| Событие | Было → стало | Время и easing | Повтор / отмена | Reduced motion |
|---|---|---|---|---|
| Раскрытие карточки | закрыта → открыта | 160 мс, ease-out (прозрачность + сдвиг 4 px), CSS | перезапуск анимации | без анимации |
| Закрытие карточки | открыта → закрыта | 140 мс, ease-in, Web Animations API | повторный клик завершает предыдущую | закрывается сразу |
| Смена статуса | старый → новый | 600 мс, вспышка цветом нового статуса | новая смена заменяет вспышку | без вспышки |
| Наведение на контролы | покой → наведение | 120 мс, цвет рамки | — | без перехода |

Проверено в браузере: анимация раскрытия запускается, закрытие и отмена работают, при `prefers-reduced-motion` закрытие мгновенное, правило `@media` есть.
Не анимируется: график состояния (перерисовывается целиком), переходы между разделами.

## 6. Контраст (проверено)

Цвета статусов и подтверждения измерены по WCAG на двух фонах карточки (`#1c1e24`, `#262931`); тест `tests/test_plan_states.py` требует не менее 4,5:1.
Заменены два цвета: «Заблокировано» `#e5484d` (4,26 / 3,72) → `#ff6b70` (6,02 / 5,26); «Отменено» `#6b7080` (3,38 / 2,95) → `#8f94a0`, плюс перечёркивание названия, чтобы различие не держалось на цвете.

## 7. Адаптивность (проверено)

Четыре страницы (UI/UX, карта, черновик, MASTER) на 375 и 768 px: горизонтальной прокрутки нет, панель фильтров не выходит за экран (исправлено `max-width:100%` у элементов фильтров). На телефоне карточка складывается в столбец и остаётся читаемой; строка карточки высокая (около 160–175 px) — это потенциальное улучшение, не дефект.
