## Действия (по порядку)

1. Войти в GitHub (один раз), в терминале проекта:

        gh auth login -h github.com -p https -w

   Откроется код для `github.com/login/device`. Подтвердить в браузере. Проверить: `gh auth status`.

2. Создать **приватный** репозиторий и убедиться в приватности до push:

        gh repo create aion-chat-watcher --private --source . --remote origin
        gh repo view --json visibility,nameWithOwner

   Поле `visibility` обязано быть `PRIVATE`. Если иначе — остановиться, push не выполнять.

3. Повторить проверку секретов на момент push (если с 12.10 были новые коммиты): `python tools/secret_scan.py` (только чтение, значения маскируются; код выхода 1 — найдено).

4. Отправить ветки и теги:

        git push -u origin feat/chat-watcher codex/next codex/ui-42-tabs master
        git push origin --tags

5. Сделать основной ветку `feat/chat-watcher` (иначе по умолчанию будет старая `master`):

        gh repo edit --default-branch feat/chat-watcher

6. Записать в `PAIR.md` и `docs/NEXT_STEPS.md`: адрес репозитория, дата первого push, SHA головы.
