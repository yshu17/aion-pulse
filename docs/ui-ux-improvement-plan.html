Правила проекта для работы над интерфейсом

Карта: сбор не возвращать; задания — только под галочкой «Задания»; порталы — только игровые (проход в тоннель Силентера, врата Бездны, выходы Силентеры).
POI-значки: только игровые из клиента (увеличенные Waifu2x, tools/upscale_icons.py); aiondb — только если в клиенте нет.
Геопривязка и количество точек проверяются отдельно от визуального редизайна.
Пункты 18 и 30: подтвердить актуальность на текущем интерфейсе; анимация поиска необязательна.

Основа дизайн-системы и критерии

Показать ограничения, критерии готовности и исходный план

Направление: тёмная компактная панель с одним тёплым акцентом. Сохраняем игровые цвета качества предметов, высокую читаемость текста и готовые значки карты.

Ограничения Tk: нет теней, размытия и прозрачности отдельных виджетов; глубина достигается цветом и 9-slice. Анимации короткие, дешёвые и отключаемые; перемасштабирование карты не анимировать.

Критерии завершения: контраст текста не ниже 4.5:1; контуры контролов от 3:1; окно 1000×600 без обрезанных элементов; пустые/загрузочные/ошибочные состояния; видимый фокус клавиатуры; проверка масштабов 100/125/150%; тесты проходят и exe собирается.

Полные обоснования, палитра, типографика, дизайн-токены и риски находятся в исходном Markdown-плане.

Статусы интерактивной страницы сохраняются только в localStorage браузера. Для изменения самого плана редактируй Markdown и пересобирай страницу: python tools/build_ui_ux_plan.py.
