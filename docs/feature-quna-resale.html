DRAFT-01 · Калькулятор кюны и перепродажи

DRAFT — Черновик / Ожидает проверки Claude Code
Добавлено: 12.10.2026 01:44. Это подготовительный план, разработка не утверждена.

Помочь сравнить варианты покупки, продажи и перепродажи по введённым пользователем величинам, не подставляя неподтверждённые правила сервера.

Пользовательские сценарии
  • Игрок вводит цену приобретения, ожидаемую цену продажи и известные ему расходы, затем видит расчёт с явными допущениями.
  • Игрок сохраняет несколько вариантов и сравнивает их без передачи данных третьим сторонам.
Функциональные требования
  • Определить единицы валюты и правила округления только после проверки версии сервера.
  • Показывать происхождение каждого коэффициента: ввод пользователя, проверенный источник либо неизвестно.
  • Разделять ввод, результат и неопределённость; не обещать доходность и не выполнять торговые действия.
Неподтверждённые игровые механики и данные
  • Курс и способы получения кюны на сервере
  • Комиссия, ограничения и правила перепродажи
  • Допустимость автоматизированного получения рыночных цен

Для дальнейшей проработки Claude Code
  1. Архитектурные вопросы: Решить, где хранить сценарии и как отделить расчёт от UI и config.json.
  2. Недостающие игровые данные: Проверить валюты, комиссии, лимиты и правила сервера.
  3. Необходимые исследования: Проверить разрешённость источников цен и жизненный цикл данных.
  4. Варианты пользовательского интерфейса: Сравнить компактную вкладку, отдельное окно и панель сравнения.
  5. Идеи анимаций и интерактивности: Оценить мягкое обновление результата без скачка чисел и с reduce_motion.
  6. Необходимые диаграммы: Поток: ввод → проверка → расчёт → объяснение результата.
  7. Технические риски: Устаревший курс, неверные единицы, ложная точность, хранение личных сумм.
  8. Вопросы, требующие решения владельца: Какие операции и валюты действительно нужны; допустим ли только ручной ввод?
  9. Предлагаемые следующие этапы: Подтвердить механику, утвердить формулу и границу MVP, затем составить технический план.
