## High

1. `watcher/config.py`: `save_config` пишет прямо в рабочий `config.json`. Прерывание записи может оставить неполный JSON; следующий `load_config` молча заменит его настройками по умолчанию. **Claude:** согласовать резервную копию и атомарную замену файла, явное сообщение пользователю и тест восстановления. Не менялось Codex из-за риска потери существующей пользовательской конфигурации.
2. `watcher/tailer.py`: `_buf` растёт без предела, если в Chat.log длительно поступают байты без `\n`. Память ограничена только размером такой строки. **Claude:** выбрать лимит и поведение для повреждённой строки; добавить тест и диагностическую запись. Обычный длинный сеанс с корректными строками не воспроизводит эту проблему.

## Medium

1. `watcher/app.py::_tick` перехватывает любое `Exception` при обработке и показывает только текст в статусе. Повторяющаяся ошибка будет возникать на каждом опросе без трассировки. **Claude:** добавить ограниченный журнал ошибок и тест восстановления после единичного сбоя.
2. `watcher/config.py::load_config` проверяет, что корень JSON — объект, но не типы полей. JSON вида `{\"keywords\": null}` проходит загрузку и может сломать интерфейс позже. **Claude:** валидация/миграция схемы настроек.
3. Для зоны Бездны `400010000` нет `data/maps/relief/ab1_1.jpg`; все остальные 15 зон имеют рельеф. Тема «Рельеф» в Бездне отображает игровую карту по предусмотренному fallback. **Claude:** решить, скрыть там тему или добавить корректный источник рельефа после проверки клиента.
4. `docs/plan-model.json` генерируется из четырёх источников, а личные отметки UI/Telegram дополнительно лежат в старых ключах `localStorage`. Общий обзор синхронизирует их, но проверка при реальном браузерном переносе не проведена. **Claude:** провести просмотр пяти страниц и мобильной публикации на телефоне.
5. Требования в `requirements.txt` содержат только нижние границы (`pytest>=8`, `pyinstaller>=6`, `Pillow>=10`), а `build_exe.bat` всегда запускает `pip install`. Повторная сборка может получить отличающиеся версии или скачать их вне проектной папки, вопреки правилу пользователя о загрузках. Текущую устарелость библиотек аудит без сетевой проверки не утверждает. **Claude:** зафиксировать проверенное окружение и убрать неявную сетевую установку из сборочного шага.
