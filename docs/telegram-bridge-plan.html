Этапы

Схема и правила передачи

Chat.log → Aion Chat Watcher → [3.Поиск группы] → пачки → закрытая группа
Поиск совпадений → отдельное сообщение → личка пользователя

Группа

  • Только канал 3.Поиск группы, включая вариант с битой кодировкой канала.
  • Пачки без звука, максимум 20 сообщений за любое окно 60 секунд.
  • Собственный слушатель лога работает по галочке независимо от Start и вкладки.
  • Исторические строки не отправляются.

Личка

  • Только новые совпадения после Start, по одному сообщению.
  • Совпадения из истории не отправляются; уведомление со звуком.
  • Для начала нужно один раз открыть бота и отправить /start.
  • Очередь личных сообщений соблюдает ограничение Telegram на частоту отправки.
Подготовленная логика пачек уже реализована в watcher/tgbatch.py и покрыта тестами. Остальная отправка ещё не реализована.

Что понадобится от пользователя

  1. Создать бота через @BotFather и получить токен.
  2. Для группового чата создать закрытую группу, добавить бота и написать туда сообщение.
  3. Для личных уведомлений открыть бота и отправить /start.
  4. В будущем интерфейсе нажать «Найти чаты» и выбрать адресатов.

Токен — пароль: хранить только в локальном config.json, не в Git и не вместе с exe.

Безопасность и ограничения

  • Бот пишет только в два явно выбранных чата.
  • Группа должна быть закрытой: в неё передаются сообщения других игроков из выбранного канала.
  • При отсутствии сети строки временно копятся в ограниченной очереди до 500; при переполнении удаляются самые старые.
  • Ошибки Telegram и 429 обрабатываются с ожиданием, указанным сервером.
  • Используется стандартная библиотека Python urllib, без новых зависимостей.
