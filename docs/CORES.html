reminders 61 стр.тестов: 8

Напоминания расписания: какие события скоро начнутся и ещё не объявлены.

flowchart LR EV[события + occurrences] --> DR[due_reminders] DR --> ST{до начала ≤ lead?} ST -->|да, ещё не объявлено| RM[напоминание]
Функции и классы
  • starts_at(event, day_start) — Start of the event in the week that begins at day_start (a Monday, 00:00).
  • week_start(now) — Monday 00:00 of the week that contains now.
  • reminder_key(event, at) — Stable id of one occurrence: the same event in the same week is announced once.
  • due_reminders(events, now, lead_min, sent) — Events that start within lead_min minutes from now (not in the past), not yet in sent.
  • occurrences_between(events, after, until) — Weekly occurrences that started in (after, until], earliest first (SN-8: missed while the program was closed).

    schedule_view 147 стр.тестов: 17

    Чистые представления расписания: next_events, day_blocks, group_of, day_label, clock_pair, map_for.

    flowchart LR E[события сетки + свои] --> NX[next_events] E --> DY[events_for_day] DY --> DB[day_blocks: минуты, дорожки] DY --> GR[group_of → groups] NX --> BD[until_text / day_label]
    Функции и классы
    • events_for_day(events, day) — Events starting on ``day``, ordered by their start time.
    • today_events(events, now) — Events whose listed start day is today in MSK.
    • next_events(events, now, limit) — Next weekly occurrences, including events running at ``now``.
    • kind_of(event) — SN-7: the event's kind for the filter («Арены» groups the arena brackets); without one, its own name.
    • kinds(events) — Each kind once, in the order of the data.
    • visible(events, hidden) — The events whose kind is not hidden by the filter.
    • map_for(event, side) — SN-7 «На карте»: the zone map id of an event (field «maps»); of two zones, the one of the player's side —
    • day_blocks(events) — Day strip: ``(event, start, end, lane)`` in minutes from midnight, sorted by start; an event that runs past
    • groups(events) — The groups present in ``events``, in the menu order (Прочее goes last, «Свои» is the own events).
    • group_hidden(events, hidden_groups) — Events whose group is not hidden by the group filter.
    • group_of(event) — Section of the schedule for an event: by its kind (or name when it has none).
    • day_label(day, now, today) — «Сегодня» for the current weekday, else «ВТ 13.10» — the date of that weekday in this week.
    • clock_pair(utc_now, local_tz) — Server time (MSK, UTC+3) and this computer's time, both as HH:MM:SS.
