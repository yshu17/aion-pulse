# Передача задачи Codex

Codex не видит инструменты Claude Code (Skill, субагенты), поэтому задача передаётся текстом. Текст собирается из
`docs/plan-ai-tools.json` и плана — переписывать вручную не нужно:

```text
python tools/plan_ai_tools.py codex map:29
```

Тот же текст есть в карточке задачи любой страницы плана: «AI Tools & Skills» → «Задание для Codex» → «Копировать».
Очередь готовых задач — фильтр «Задачи для Codex · готовы» в общем обзоре или блок «Готово к передаче Codex» на MASTER.

## Когда задачу можно передавать

`handoff: ready` ставит только Claude, и только если Codex может начать без нового решения:
контракт записан (`contract`), файлы назначены (`files.Codex`), критерии и тесты есть, зависимости выполнены или указаны.
`needs-architecture` — сначала решение Claude; `gated` — план ждёт «делаем» пользователя; `blocked` — ждёт предыдущих этапов.

## После работы Codex

1. Codex: тесты, строка в `PAIR.md`, своя ветка `codex/<задача>`.
2. Claude: diff, `python tools/check_project.py`, проверка критериев, слияние, статус в исходном плане, пересборка планов.
3. Расхождение с контрактом — вопрос в `docs/PROJECT_ISSUES.md`, а не правка контракта Codex-ом.
