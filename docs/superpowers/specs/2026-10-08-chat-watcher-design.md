# Aion Chat Watcher — дизайн

Дата: 2026-10-08

## Цель

Программа в реальном времени следит за чатом Aion и подаёт звуковой сигнал, когда в канале
«Поиск группы» появляется сообщение с одним из ключевых слов, заданных пользователем.

## Источник данных

Клиент Aion пишет весь чат в текстовый файл:

- папка игры: `C:\aMain\Games\AION Imperia\Aion Empire`;
- файл лога: `<папка игры>\classic\Chat.log`;
- кодировка cp1251, переводы строк CRLF;
- файл большой (сотни МБ) и постоянно дописывается в конец.

Формат строки игрока в нужном канале:

```
2026.10.08 18:43:17 : [3.Поиск группы] [charname:Tiyamate;1.0000 0.6941 0.6941]: [cmd:Tiyamate;sxFs...=]WTB MMK 2.2KK SM
```

Остальные строки (баффы, HP/MP, эмоции, другие каналы) игнорируются.

OCR не используется. Программа только читает файл: не трогает клиент, память игры и ввод.

## Стек

- Python 3.11+
- tkinter — окно
- winsound — звук
- только стандартная библиотека в runtime
- pytest — тесты
- PyInstaller — сборка `AionChatWatcher.exe` (`build_exe.bat`), как в `aion_craft_bot`


## Модули

### tailer.py — `LogTailer`

- `LogTailer(path, encoding="cp1251")`.
- `start_at_end()` — запомнить текущий размер файла как позицию. Старое содержимое не читается.
- `read_new_lines() -> list[str]`:
  - открыть файл в бинарном режиме, перейти на сохранённую позицию, прочитать новые байты;
  - вернуть только полные строки (до `\r\n` / `\n`), декодированные из cp1251 с `errors="replace"`;
  - недописанный хвост держать в буфере до следующего вызова;
  - если размер файла меньше позиции (файл пересоздан или очищен) — сбросить позицию в 0 и буфер;
  - если файла нет — бросить `FileNotFoundError` (обрабатывает `app.py`).
- Файл открывается и закрывается на каждом чтении, чтобы не держать блокировку и не мешать игре.

### parser.py — `parse_line(line) -> ChatMessage | None`

- `ChatMessage(time: str, nick: str, text: str, raw: str)`.
- Шаблон: `^(\d{4}\.\d{2}\.\d{2} \d{2}:\d{2}:\d{2}) : \[3\.Поиск группы\] \[charname:([^;\]]+);[^\]]*\]: (.*)$`.
- Префикс канала задаётся константой `CHANNEL = "[3.Поиск группы]"`.
- Очистка текста:
  - удалить `[cmd:...]`;
  - заменить `[item:...]` на `[item]`;
  - обрезать пробелы по краям.
- Строки, не подходящие под шаблон, дают `None`.
- Ник в поиске не участвует: ключевые слова ищутся только в очищенном тексте.

### matcher.py — `Matcher`

- `Matcher(keywords: list[str], cooldown_sec: float = 60)`.
- `set_keywords(keywords)` — замена слов на лету. Пустые строки и пробелы отбрасываются.
- Нормализация текста и слов: `lower()` и замена `ё` на `е` (длина строки сохраняется — нужно для
  подсветки).
- `highlight_segments(text, keywords) -> list[tuple[str, bool]]` — текст, разбитый на куски
  «совпало / не совпало» для подсветки в окне.
- `check(msg, now: float) -> list[str]` — список совпавших слов (подстрока, исходное написание
  слова). Пусто — совпадения нет.
- Анти-спам: ключ `(ник, нормализованный текст)`. Если тот же ключ уже совпадал меньше
  `cooldown_sec` секунд назад, `check` возвращает пусто. Старые ключи периодически чистятся.
- `now` передаётся снаружи, чтобы тесты не зависели от времени.

### notifier.py — `Notifier`

- `Notifier(sound_path: str | None)`.
- `play()` — `winsound.PlaySound(path, SND_FILENAME | SND_ASYNC)`; если путь пустой или файла нет —
  `winsound.MessageBeep(MB_ICONEXCLAMATION)`.
- Асинхронно: окно не блокируется.

### config.py

`config.json`:

```json
{
  "game_dir": "C:\\aMain\\Games\\AION Imperia\\Aion Empire",
  "chat_log": "",
  "keywords": [],
  "poll_interval_ms": 500,
  "cooldown_sec": 60,
  "sound_path": ""
}
```

- Путь к логу: `chat_log`, если задан; иначе `game_dir\classic\Chat.log`.
- Нет файла или битый JSON — значения по умолчанию, файл перезаписывается.
- Сохранение при изменении слов и пути. Файл лежит рядом с exe / `main.py`.

### app.py — окно

- Поле «Папка игры» + кнопка выбора папки.
- Поле «Ключевые слова» (через запятую). Применяются после редактирования (по Enter и по
  потере фокуса), сохраняются в конфиг.
- Кнопки: Start / Stop, «Тест звука».
- Статус: «Остановлен», «Слежу за …\Chat.log», «Chat.log не найден», текст ошибки чтения.
- Список совпадений (новые сверху, максимум 500): `время  ник: текст`, совпавшее слово
  подсвечено тегом Text-виджета.
- Цикл: `root.after(poll_interval_ms)` → `read_new_lines` → `parse_line` → `matcher.check` →
  при совпадении `notifier.play()` (один звук на пачку строк) и запись в список.
- Ошибки:
  - нет файла — статус «Chat.log не найден», повтор каждые 2 с, при появлении начать с конца файла;
  - `OSError` при чтении — показать в статусе, продолжить опрос.
- Start всегда начинает с конца файла: старые сообщения не вызывают сигналов.

## Тесты

- `test_parser.py`: реальные строки из лога — сообщение игрока с `[cmd:...]`, с `[item:...]`,
  без ссылок; системная строка; другой канал; битая строка.
- `test_matcher.py`: регистр, `ё`/`е`, несколько слов, пустые слова, анти-спам (повтор внутри и
  после `cooldown_sec`, другой ник = новое совпадение).
- `test_tailer.py` на временном файле: старт с конца, дописывание, частичная строка, cp1251,
  пересоздание файла (размер уменьшился), отсутствующий файл.
- GUI и звук проверяются вручную: запуск, Тест звука, совпадение на живом чате.

## Вне скоупа

Telegram, toast-уведомления, regex, другие каналы, игнор-лист ников, поиск по истории лога.
