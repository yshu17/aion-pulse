> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** layers of points (functional NPCs, portals, artifacts, gathering, quest points) with filters, search and a «Рядом» card on the «Карта» tab.

**Architecture:** a build tool turns the client TSVs (extracted by Codex) into one compact `data/maps/poi.json`; `watcher/poi.py` is a Tk-free data layer (load, filter, search, nearest, clusters); `watcher/mapview.py` draws it. Progress for the user is shown in `docs/map-poi-plan.html` (each step has a status field that is updated and committed after the step).

**Tech Stack:** Python 3.14, tkinter, Pillow (already a runtime dependency), pytest.

**Spec:** `docs/superpowers/specs/2026-10-09-map-poi-design.md`

### Task 3: `watcher/poi.py` (plan step 3)

**Files:** Create `watcher/poi.py`, `tests/test_poi.py`

**Interfaces — produces:**
```python
@dataclass(frozen=True)
class Poi: zone: str; type: str; x: float; y: float; gx: float; gy: float; name: str
class PoiStore:
    types: dict[str, dict]                 # from poi.json
    def load(path: Path) -> "PoiStore"     # classmethod; broken/missing -> empty store
    def in_zone(self, zone: str, types: set[str]) -> list[Poi]
    def search(self, zone: str, query: str, types: set[str]) -> list[Poi]   # case/«ё»-insensitive on name and type name
    def nearest(self, zone: str, gx: float, gy: float, type_: str) -> tuple[Poi, float] | None  # metres
    def counts(self, zone: str) -> dict[str, int]
def cluster(points: list[Poi], to_screen, radius_px: float) -> list[tuple[float, float, list[Poi]]]
```
