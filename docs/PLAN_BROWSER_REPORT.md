## Импорт native-only отметок (UI45-02)

Старый экспорт: отметки, которых нет в журнале, теперь переносятся в журнал с записью в историю (`origin: импорт старого экспорта (native)`). Старые ключи пишутся как раньше, ничего не удаляется. Откат возвращает состояние до последнего импорта.
