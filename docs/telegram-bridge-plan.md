# Telegram: трансляция живого чата в группу — логика и план

Статус: **объём согласован, ждёт команды «делаем».** Ничего ещё не сделано.

Решение: **только живой чат** — то же, что показывает вкладка «Весь чат». Без поиска, без алертов,
без выделения совпадений, без команд в группе. Это можно добавить позже отдельными этапами.

## Как это будет работать

```
Chat.log ──► Aion Chat Watcher ──► фильтр «Весь чат» ──► очередь ──► отправщик (отдельный поток) ──► Telegram ──► группа
```

1. Программа читает `Chat.log` в реальном времени (как сейчас).
2. Строки проходят тот же фильтр, что и вкладка «Весь чат»: Поиск группы, общий, личные,
   группа, легион; «Информация и уведомления» — если включена галочка во вкладке.
3. Отдельный поток раз в 3 с склеивает новые строки в одно сообщение и отправляет боту
   `sendMessage` в группу. Окно программы не подвисает.
4. Трансляция работает, пока включена галочка «Telegram» — независимо от Start и от того,
   открыта ли вкладка «Весь чат». История за прошлые минуты не отправляется, только новое.

Почему пачками: Telegram пускает бота примерно на **20 сообщений в минуту в одну группу**.
Пачка раз в 3 с = не больше 20 сообщений в минуту, строки не теряются.

### Пример сообщения в группе

```
21:43:17 [3.Поиск группы] Seller: WTS [Клинок Рудры] 5кк
21:43:20 [Группа] Tiyamate: идём в пхасу
21:43:25 [Личное] Pyro: го?
```

Сообщения отправляются **без звука** (`disable_notification`), чтобы группа не пищала на каждую пачку.

## Что понадобится от тебя (один раз)

1. **@BotFather** → `/newbot` → имя → получить **токен** вида `123456:ABC...`.
2. Создать закрытую группу, добавить туда бота.
3. Написать в группе любое сообщение. Кнопка «Найти группу» в программе сама найдёт её номер
   (`chat_id`) через `getUpdates`.
4. Вставить токен в программу.

## Безопасность и ограничения

- **Токен = пароль от бота.** Хранится только в `config.json` рядом с exe (не в git, не в exe).
  Не пересылай exe вместе с `config.json`.
- Бот пишет только в одну выбранную группу.
- В группу уходят сообщения **других игроков** — группа должна быть закрытой.
- Нет связи → строки копятся (до 500), уйдут при восстановлении; в статусе «Telegram: нет связи».
- `429 Too Many Requests` → ждём `retry_after`, потом отправляем.
- Только стандартная библиотека Python (`urllib`), без новых зависимостей.
