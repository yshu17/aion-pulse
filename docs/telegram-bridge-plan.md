# Telegram: трансляция чата в группу — логика и план

Статус: **черновик, ждёт решения.** Ничего из этого ещё не сделано. Отмечай пункты «делать / не делать».

## Как это будет работать

```
Chat.log ──► Aion Chat Watcher ──► очередь ──► отправщик (отдельный поток) ──► Telegram Bot API ──► твоя группа
                (как сейчас)                    пачки раз в N секунд
```

1. Программа уже читает `Chat.log` в реальном времени. Новые строки, которые прошли фильтр
   (см. «Что отправлять»), кладутся в очередь.
2. Отдельный поток раз в несколько секунд забирает всё из очереди, склеивает в одно сообщение
   и отправляет боту `sendMessage` в группу. Окно программы при этом не подвисает.
3. Бот пишет в группу от своего имени. Ты (и кого добавишь) читаете с телефона.

Почему пачками, а не по строке: Telegram ограничивает бота примерно **20 сообщений в минуту
в одну группу**. В «Поиске группы» бывает 5–10 строк в минуту, в часы пик больше — по одной строке
бот упрётся в лимит. Пачка раз в 3–5 с = максимум 12–20 сообщений в минуту, ничего не теряется.

### Пример сообщения в группе

```
🔍 21:43:17  Seller: WTS [Клинок Рудры] 5кк
🔍 21:43:20  Tiyamate: WTB ММК 2.2КК
⚠️ 21:43:25  Pyro: wts DP S          ← совпадение по поиску (жирным)
```

## Что отправлять (выбор)

| Вариант | Что уходит в группу | Объём |
|---|---|---|
| A. Только совпадения | то, что сейчас звенит (слова/предметы по режиму поиска) | мало |
| B. Весь «Поиск группы» | все строки канала 3, совпадения выделены | ~300/час |
| C. Как вкладка «Весь чат» | Поиск группы + общий + личные + группа + легион | больше |

Рекомендую **B с выделением совпадений** — видно всё, важное заметно. A — если нужна тишина.
Выбор будет в настройках, можно менять на ходу.

## Что понадобится от тебя (один раз)

1. В Telegram написать **@BotFather** → `/newbot` → имя → получить **токен** вида `123456:ABC...`.
2. Создать группу, добавить туда бота.
3. Написать в группе любое сообщение. Программа сама найдёт **chat_id** группы
   (кнопка «Найти группу» через `getUpdates`), вручную ничего искать не нужно.
4. Вставить токен в настройки программы.

## Безопасность и ограничения

- **Токен = пароль от бота.** Хранится только в `config.json` рядом с exe (он не попадает в git
  и не вшивается в exe). Не пересылай exe вместе с `config.json`.
- Отправка только в **одну** указанную группу (`chat_id`), бот никуда больше не пишет.
- В группу уходят сообщения **других игроков** из игрового чата. Группа должна быть закрытой,
  только для своих.
- Нет интернета / Telegram недоступен → строки копятся в очереди (до ~500), отправятся при
  восстановлении; старее — отбрасываются, в статусе видно «Telegram: нет связи».
- Ответ `429 Too Many Requests` → ждём столько, сколько сказал Telegram (`retry_after`), потом шлём.
- Только стандартная библиотека Python (`urllib`), новых зависимостей и программ нет.
