# Для Кодекса

Работаем в паре с Claude. Перед любой работой прочитай `PAIR.md` (правила, задачи, журнал), после работы
допиши туда строку в журнал и обнови статус шага в `docs/map-poi-plan.html`.

Проектные инструкции Claude — `.claude/skills/*/SKILL.md`. Для планирования, архитектуры, UI/UX и движения читай
соответствующий SKILL.md и его `references/`; инструменты Claude Code в них (Skill, субагенты) замени своими.
